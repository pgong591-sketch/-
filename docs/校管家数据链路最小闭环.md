# 校管家数据链路最小闭环

## 当前结论

- 本机当前没有发现 `pyxgj`：项目内无引用，系统 Python 和项目虚拟环境都无法导入。
- 校管家官方开放平台可用，已确认存在 `获取access_token`、`批量获取课消信息`、学员、课程、班级、订单等接口。
- 当前账号没有提供开放平台凭证，因此实际最小闭环走只读网页登录态：`校管家报表接口 -> 本地 JSON -> Python -> Polars DataFrame`。
- 登录、短信验证或扫码只由账号本人正常完成；程序不保存密码，不破解验证码，也不调用写接口。

## 已确认的网页登录态接口

- 页面：报表中心 / 课消报表 / 学员课消明细表
- 请求：`POST /api/report/QueryReportConsumeDetail`
- 数据格式：`application/x-www-form-urlencoded`
- 日期参数：`sDate`、`eDate`
- 分页参数：`PageIndex`、`PageSize`；第 0 页和第 1 页都会返回首页，后续页从 2 开始
- 总数与分页：响应 `TotalCount`、`PageCount`、`Data.data`
- 校区参数来自当前账号在页面中选择的校区，运行时读取，不写入源码

当前课消范围可用一个大页面完整读取，避免页间数据变化；若以后数据超过单页上限，必须按上述页码规则继续读取。
浏览器在下载前核对 `实际行数 == TotalCount`。本地文件保存在
`xgj_runtime/`，该目录已排除在 Git 之外。Cookie、Token、校区标识和学员明细均不写入文档或日志。

## 官方 API 信息

- 文档首页：`https://api.xiaogj.com/`
- 获取 token：`GET {url}/token?appid=APPID&secret=APPSECRET`
- 批量课消：`GET {url}/fin/get_receipt_consume_batch`
- 课消参数：`access_token`、`updatetime`、`updateTimeEnd`、`offset`、`size`
- 分页字段：`has_more`、`count_number`、`data`
- 最大分页大小：`size <= 100`

敏感值只允许从运行环境读取，不能写进代码或文档。

## 本地配置

在本机 `.env` 放入：

```bash
XGJ_API_BASE_URL=https://api.xiaogj.com
XGJ_APPID=你的AppId
XGJ_APPSECRET=你的AppSecret
```

如校管家返回的 `offset` 实际是页码而不是偏移量，再补：

```bash
XGJ_PAGE_MODE=page
```

## 调用方式

```python
from xgj_client import XGJClient

client = XGJClient()
df = client.get_consume_details("2026-08-31", "2026-09-06")

print(df.shape)
print(df.columns)
print(df.head())
```

`XGJClient` 默认使用 `auto`：同日期的浏览器取数文件存在时直接读入，否则尝试官方 API。
可以在本地环境中明确指定：

```bash
XGJ_SOURCE=browser_capture
XGJ_CAPTURE_DIR=xgj_runtime
```

也可以直接运行：

```bash
.venv/bin/python scripts/xgj_smoke.py
```

## 安全边界

- 当前实现只读，只访问报表查询接口。
- 不保存账号密码、Cookie、Token。
- 错误信息会脱敏 `access_token/appid/secret/cookie/authorization`。
- `.env` 已在 `.gitignore` 中。
- 浏览器 Profile、Cookie、Token 如后续启用，也必须只放本地且进 `.gitignore`。
