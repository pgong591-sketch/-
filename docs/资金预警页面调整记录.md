# 资金预警页面调整记录

记录日期：2026-07-07

用途：记录经营中心“资金预警”页面的资金周转口径、筛选范围、风险状态和展示规则。

## 2026-07-07 资金预警页面第一版

结论：
- 资金预警从模板规则推进到可浏览页面，默认只看资金有风险的单体公司。
- 第一版先用科目余额表和经营成本数据计算资金周转系数，不把缺数据公司误判为安全。

调整点：
- 新增“资金预警”入口。
- 查看范围包括：全部单体公司、只看校区、只看管理中心、只看书馆、只看资金预警公司。
- 默认状态为“预警公司”，即只展示资金周转系数低于 3 的公司。
- 资金状态分为：资金紧张、资金关注、资金安全、资金数据待接入、成本数据待接入。
- 可使用周转资金按“货币资金 + 其他应收款 - 其他应付款 + 实收资本未达账”计算。
- 资金周转系数按“可使用周转资金 / 近 6 月平均经营成本”计算。
- 没有科目余额数据时显示资金数据待接入，不当作 0 也不当作安全。
- 科目余额为 0 但有数据时按真实 0 计算。
- 集团资金周转系数使用汇总后的可使用周转资金和成本计算，不取最低单体值。
- 对外投资模块和指定投资范围不参与集团周转系数汇总。
- 表格支持按风险、资金周转系数、可使用周转资金、公司名称排序。

影响范围：
- 经营中心资金预警页面。
- 科目余额表资金类科目取数。
- 收入成本费用明细中的近 6 月经营成本。
- 资金预警相关测试。

待确认：
- 资金预警阈值是否固定为 3，还是后续可配置。
- 实收资本未达账是否需要单独上传或维护。
- 其他应收、其他应付是否需要进一步限定“校区往来”辅助口径。

下一步：
- 用真实科目余额表和经营成本数据核对资金周转系数。
- 确认管理中心、书馆、校区的范围划分。
- 后续再决定是否导出资金预警表。

## 2026-07-15 表格阅读补充

结论：
- 资金预警表格增加固定表头和固定首列，方便横向核对公司资金数据。

调整点：
- 表格区域支持横向和纵向滚动。
- 表头固定在顶部。
- 公司列固定在左侧。
- 表格高度限制为页面高度的一部分，避免长表撑开整个页面。

影响范围：
- 资金预警页面表格。
- 首页资金安全和资金周转风险下钻。

## 2026-07-27 资金管理模块口径补充

结论：
- 资金管理模块补齐了首页资金卡片和资金预警明细的同一套资金口径，避免首页汇总和明细表解释不一致。
- 资金类只取科目余额表，不再从资产负债表兜底取数。

调整点：
- 首页“资金安全”卡片新增资金保障能力：近 6 月月均经营成本、3 个月安全资金线、集团资金周转系数、安全余量和状态结论。
- 首页“资金周转风险”卡片展示资金紧张、资金关注、资金安全公司数，并列出 Top5 风险公司。
- 首页资金卡片和资金预警表共用核心计算，按当前公司范围汇总；资金数据缓存同时考虑数据库数据变化。
- 资金预警汇总行不展示“实收资本未达账”细列，但计算口径继续保留该项。
- 货币资金优先取“货币资金”父级或现金、银行存款、其他货币资金父级科目；父级不存在时再回退到子级明细。
- 其他应收款、其他应付款只取“公司往来”辅助口径，不把押金、个人往来、预提费用等混进可使用周转资金。
- 父级公司不自动汇总子公司资金；父级有自身数据才显示，没自身数据就保持资金数据待接入。
- 非叶子管理中心和尔遇书馆管理中心使用自身资金数据，不包含下级书馆、校区或子公司。
- 对外投资模块继续排除在集团资金周转系数汇总之外。
- 资金状态规则保持：小于 2 为资金紧张，2 到 3 为资金关注，3 及以上为资金安全；缺资金或缺成本时分别显示待接入。

影响范围：
- 经营中心资金预警页面。
- 首页资金安全卡片。
- 首页资金周转风险卡片。
- 科目余额表资金类科目取数。
- 首页与资金预警相关测试。

待确认：
- 3 个月安全资金线是否作为长期固定安全线。
- 实收资本未达账后续是否需要独立维护入口。
- 公司往来辅助口径是否需要在导入时做更严格校验。
