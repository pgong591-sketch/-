# 资金预警页面调整记录

记录日期：2026-07-07

用途：记录经营中心“资金预警”页面的资金周转口径、筛选范围、风险状态和展示规则。

## 2026-07-07 资金预警页面第一版

结论：
- 资金预警从模板规则推进到可浏览页面，默认只看资金有风险的单体公司。
- 第一版先用科目余额表和经营成本数据计算资金周转系数，不把缺数据公司误判为安全。

调整点：
- 新增“资金预警”入口。
- 查看范围包括：全部单体公司、只看校区、只看管理中心、只看书馆、只看资金预警公司。
- 默认状态为“预警公司”，即只展示资金周转系数低于 3 的公司。
- 资金状态分为：资金紧张、资金关注、资金安全、资金数据待接入、成本数据待接入。
- 可使用周转资金按“货币资金 + 其他应收款 - 其他应付款 + 实收资本未达账”计算。
- 资金周转系数按“可使用周转资金 / 近 6 月平均经营成本”计算。
- 没有科目余额数据时显示资金数据待接入，不当作 0 也不当作安全。
- 科目余额为 0 但有数据时按真实 0 计算。
- 集团资金周转系数使用汇总后的可使用周转资金和成本计算，不取最低单体值。
- 对外投资模块和指定投资范围不参与集团周转系数汇总。
- 表格支持按风险、资金周转系数、可使用周转资金、公司名称排序。

影响范围：
- 经营中心资金预警页面。
- 科目余额表资金类科目取数。
- 收入成本费用明细中的近 6 月经营成本。
- 资金预警相关测试。

待确认：
- 资金预警阈值是否固定为 3，还是后续可配置。
- 实收资本未达账是否需要单独上传或维护。
- 其他应收、其他应付是否需要进一步限定“校区往来”辅助口径。

下一步：
- 用真实科目余额表和经营成本数据核对资金周转系数。
- 确认管理中心、书馆、校区的范围划分。
- 后续再决定是否导出资金预警表。

## 2026-07-15 表格阅读补充

结论：
- 资金预警表格增加固定表头和固定首列，方便横向核对公司资金数据。

调整点：
- 表格区域支持横向和纵向滚动。
- 表头固定在顶部。
- 公司列固定在左侧。
- 表格高度限制为页面高度的一部分，避免长表撑开整个页面。

影响范围：
- 资金预警页面表格。
- 首页资金安全和资金周转风险下钻。
