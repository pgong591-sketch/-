# 图片简报调整记录

记录日期：2026-07-06

用途：记录经营中心“图片简报”页面从 Excel 模板预览走向经营简报页面的调整过程。

## 2026-07-06 图片简报经营化第一版

结论：
- 图片简报不再只是把 Excel 模板原样嵌入页面，而是开始从收入成本费用明细数据生成经营简报。
- 月报和本年累计继续保留切换，但页面不增加经营单位筛选，避免把简报做成普通查询表。

调整点：
- 图片简报保留“月报 / 本年累计”切换。
- KPI 从收入成本费用明细中取经营收入、净利润、净利率、人工、租金等关键指标。
- 素质中心、其他模块、对外投资、各校区具体情况拆成简报区块展示。
- 简报说明由数据自动生成，不保留原模板里的群消息、表格编号等杂音。
- 净利润、净利率、亏损等风险项支持高亮，负数单元格单独标识。
- 各校区具体情况保持横向可滚动，避免列多时把文字挤没。
- 趋势判断使用真实多期间数据；只有单期数据时不画假趋势线。
- 模板读取增加缓存，并按文件修改时间自动失效，避免反复读 Excel 影响速度。

影响范围：
- 经营中心图片简报页面。
- 报表模板工作簿读取和 HTML 渲染。
- 收入成本费用明细数据在简报中的复用。
- 图片简报相关测试。

待确认：
- 简报 KPI 是否固定为收入、净利润、净利率、人工、租金。
- 素质中心、尔遇、管理中心等范围是否就是最终合并口径。
- 各校区具体情况是否继续沿用模板列，还是后续按经营指标重排。

下一步：
- 用真实月份数据核对简报金额。
- 财务确认简报区块和 KPI 顺序。
- 后续再决定是否导出成图片或 PPT，不在当前第一版里扩大范围。

## 2026-07-07 图片简报范围映射补充

结论：
- 图片简报进一步从模板静态表格改为按确认范围自动生成区块。
- 其他模块、对外投资、各校区具体情况都开始从收入成本费用明细里按公司范围取数。

调整点：
- 其他模块区块按学校、幼儿园、尔遇书城、茶山托育、青少年宫、探幽文旅等范围生成。
- 对外投资区块按深圳卓越、中科心研、武汉均衡、多彩维度、凤来置业、溢星空等范围生成。
- 各校区具体情况按校区清单生成，不再保留模板里的说明行、月份行、群消息等杂项。
- 没有实际数据的范围显示“待接入”或“待确认”，不编造 0。
- 图片简报缓存增加对数据库 wal/shm 文件的识别，数据库有新写入时能自动刷新。

影响范围：
- 图片简报其他模块区块。
- 图片简报对外投资区块。
- 图片简报各校区明细区块。
- 图片简报缓存刷新。

待确认：
- 其他模块和对外投资范围是否为最终管理口径。
- “待接入”和“待确认”的区分是否满足财务阅读习惯。
