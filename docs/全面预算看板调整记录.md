# 全面预算看板调整记录

记录日期：2026-07-04

用途：记录经营中心“全面预算”看板的预算读取、实际对比、校区匹配、下钻和展示口径。

## 2026-07-04 全面预算看板第一版

结论：
- 全面预算看板开始从“只看报表”推进到“预算目标 vs 实际完成”的经营看板。
- 第一版重点是收入、利润、时间进度、模块下钻和素质中心校区匹配，不处理预算表里的人工、其他费用等辅助列。

调整点：
- 预算文件默认使用项目内的 `2026年集团预算.xlsx`，不再依赖微信临时目录。
- 预算读取只保留核心字段：模块、经营单位、收入预算、利润预算、预算层级。
- 按月份计算时间进度，例如 3 月对应 25%。
- 看板按模块汇总收入预算、利润预算、收入实际、利润实际、完成率和进度差。
- 负利润预算单独处理：亏损少于预算亏损算改善，亏损扩大算滞后，不再用普通完成率误判。
- 未分组实际数据可以进入下钻，但标记为“暂无预算”，不伪造预算数。
- 只有模块级预算、没有下级单位预算时，下钻保留模块行，并把实际状态标为“待接入”。
- 增加素质中心目标校区读取和匹配逻辑，用于把预算校区与实际经营单位对上。
- 松山湖校区、产品中心直营校等特殊项目不按 0 实际简单判定异常，而是保留特殊状态说明。

影响范围：
- 经营中心导航新增“全面预算”入口。
- 预算看板页面。
- 基础设置中的预算校区名称映射。
- 预算相关测试。

待确认：
- 预算模块名称是否就是最终经营模块口径。
- 素质中心目标校区的预算金额是否只取“合并收入”列。
- 未分组实际数据是否需要强制归类，还是先保留为提醒区。

下一步：
- 用真实预算文件和真实期间数据核对模块汇总。
- 财务确认预算校区名称映射。
- 后续再补人工、费用、现金流等更细预算项，不和第一版混在一起。

## 2026-07-15 预算实际数与内部抵消补充

结论：
- 全面预算实际数改为使用收入成本费用明细的本年累计口径。
- 主表展示合并调整后的结果，下钻保留单体原始数据，并用说明解释差异。

调整点：
- 预算实际数从收入成本费用明细取本年累计，不再从普通损益表取数。
- 模块和合计层应用内部服务费抵消，下钻仍展示单体原始累计数。
- 管理中心、非学科管理中心、尔遇书馆管理中心的内部服务费分别处理。
- 预算明细里的“合计 / 合并 / 总计”等伪行会被过滤，避免重复加总。
- 已存在真实下级公司数据时，删除过期的父级重复实际数。
- 负利润预算按减亏进度判断，平均完成度只统计正预算且有实际数的经营单位。
- 主表和下钻表格增加固定表头和固定首列，方便横向滚动核对。
- 华凯校区等存在重复口径风险的映射标为待确认，不直接匹配。

影响范围：
- 全面预算看板主表。
- 全面预算模块下钻。
- 预算完成率 KPI。
- 预算校区匹配。

待确认：
- 内部服务费抵消是否完全覆盖所有预算模块。
- 下钻是否长期保留单体原始数，还是后续增加“调整后下钻”。

## 2026-07-29 预算期间与本年累计字段补充

结论：
- 全面预算的实际月份改为只看收入成本费用明细表的本年累计数据，不再被普通损益表或其他报表期间带偏。
- 收入成本费用导入结构补齐 `ytd_amount`，预算实际数可以稳定读取本年累计。

调整点：
- 收入成本费用表解析时同时写入本月金额和本年累计金额。
- 预算年份、月份下拉只从有本年累计数据的 `pl_detail` 期间生成。
- 默认月份取最新可用实际月份；切换年份时自动回到该年份最新月份。
- 如果某年还没有可用实际数，月份按安全默认值显示，并提示实际数暂未接入。
- 预算完成率 KPI 和首页预算卡片继续复用全面预算口径。
- 预算模块链接、下钻排序和关闭动作统一使用页面参数生成，避免丢失当前筛选状态。

影响范围：
- 全面预算看板。
- 首页预算执行卡片。
- 预算完成率 KPI。
- 收入成本费用表导入。

待确认：
- 历史已导入数据是否需要补跑一次，把本年累计字段补齐。
- 缺本年累计的旧文件是否允许继续进入预算实际数。
