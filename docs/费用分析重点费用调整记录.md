# 费用分析重点费用调整记录

记录日期：2026-07-04

用途：记录经营中心“费用分析”页面中重点费用分组、占比、管理费提示和页面展示规则。

## 2026-07-04 重点费用分析第一版

结论：
- 费用分析不再只是普通科目列表，新增重点费用归类视角。
- 第一版先看 6 类外部费用，并把“管理费服务费”单独提示，避免和真实外部成本混在一起。

调整点：
- 重点费用分为：人工成本、租金水电物业、折旧摊销、交际接待交通、办公行政、财务费用。
- 成本费用合计、收入合计等汇总行只作为分母，不进入明细费用重复计算。
- 折旧摊销优先使用合计行，避免折旧费、待摊费和合计行重复相加。
- 管理费服务费单独展示，不进入外部费用类别排行。
- 每个费用类别显示本月金额、占成本费用比、占收入比和主要经营单位。
- 重点费用卡片使用 HTML 渲染，但不泄漏源码标签。

影响范围：
- 经营中心费用分析页面。
- 收入成本费用明细表来源数据的费用归类。
- 费用分析相关测试。

待确认：
- 6 类重点费用是否就是正式管理口径。
- 管理费服务费是否长期保持单独提示，还是后续按内部抵消逻辑完全剔除。
- “主要经营单位”是否按金额最大主体展示，还是需要展示前三名。

下一步：
- 用真实月份数据检查 6 类费用是否覆盖主要异常。
- 财务确认管理费服务费展示方式。
- 后续再做费用项点击下钻，不在第一版里扩大范围。

## 2026-07-15 费用桥接口径补充

结论：
- 费用分析增加桥接说明，用来解释六类重点费用、管理费服务费和成本费用合计之间的差异。

调整点：
- 当成本费用合计大于六类重点费用加管理费服务费时，差额显示为“其他费用”。
- 当六类重点费用加管理费服务费超过成本费用合计时，差额显示为“待核对差额”。
- 费用分析结论明确展示“成本费用合计 = 六类重点费用 + 管理费服务费 + 其他费用 / 差额”。

影响范围：
- 费用分析卡片。
- 首页费用分析卡片组。
- 费用分析结论文案。
