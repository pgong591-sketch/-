# 损益表页面调整记录

记录日期：2026-07-03

用途：记录财务中心“损益表”页面的展示口径、公司列顺序、项目行顺序、比例计算和导出规则。

## 2026-07-03 损益表页面展示与导出调整

结论：
- 损益表页面改为按固定模板顺序展示，减少每次导入后列顺序、行顺序不稳定的问题。
- 页面展示和导出使用同一份整理后的结果，避免页面看见的内容和导出的 Excel 不一致。

调整点：
- 项目行按固定损益表模板排序，额外项目排在固定项目之后。
- 公司列优先按约定顺序展示；不在约定顺序内的公司，再按公司树和编码补到后面。
- “广东多维教育科技集团有限公司”在页面上显示为“管理中心”，避免公司名称过长影响表格阅读。
- 同名公司不会合并，会自动加编码后缀区分。
- 毛利率、净利率缺失时，页面按收入、成本、净利润自动补算。
- 毛利率、净利率只在对应比例行按百分比显示，毛利金额不再误判成百分比。
- 新增“只看核心指标”，只保留营业收入、净利润、毛利率、净利率。
- 全年累计模式只取所选月份中最后一个月份的累计数，不重复累加累计数。
- 多月份非累计模式按本月数求和。
- 负数比例在表格里高亮，便于快速发现异常。

影响范围：
- 财务中心损益表页面。
- 损益表 Excel 导出。
- 损益表页面相关测试。

待确认：
- 固定公司顺序是否就是最终管理口径。
- 固定项目行是否还要补充更多损益表项目。
- “核心指标”是否只保留当前 4 项，还是后续加入毛利、利润总额等中间项。

下一步：
- 用真实月份数据核对公司列顺序和金额。
- 核对导出 Excel 与页面展示是否一致。
- 财务确认后，把固定公司顺序和项目顺序沉淀为正式模板规则。
