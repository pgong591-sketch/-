# Mac 启动脚本调整记录

记录日期：2026-07-10

用途：记录 Mac 端后台启动脚本的稳定化调整。

## 2026-07-10 后台启动脚本防误连调整

结论：
- 后台启动脚本不再只看端口或旧进程号，而是确认 8502 端口上的服务确实属于当前项目。

调整点：
- 启动前检查旧进程是否为当前项目的 Streamlit 服务。
- 如果 8502 已被别的程序占用，直接提示启动失败，不再误打开错误页面。
- 如果当前项目已经在 8502 运行，只打开浏览器，不重复启动。
- 启动后等待服务真正监听端口，再写入进程文件并打开页面。
- 启动失败会写入日志，并在 Mac 上弹出提示。

影响范围：
- Mac 后台启动方式。
- 本地 8502 端口占用判断。
- 启动日志和失败提示。

下一步：
- 后续如果改端口，要同步改启动脚本和使用说明。
