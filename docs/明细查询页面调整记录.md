# 明细查询页面调整记录

记录日期：2026-07-15

用途：记录数据明细查询页面的表格展示、下载和大数据量处理规则。

## 2026-07-15 明细查询表格第一版

结论：
- 明细查询页面开始使用专门的 HTML 表格展示小结果，大结果自动退回普通表格，避免页面卡死。

调整点：
- 查询结果表格固定表头和首个识别列。
- 数字自动格式化，负数保留可读显示。
- 小结果使用 HTML 表格，便于冻结表头和首列。
- 超过限制行数时，不生成完整 HTML，改用普通表格并保留下载。
- 下载文件名按表类型、公司、期间生成。

影响范围：
- 数据明细查询页面。
- 损益明细、科目余额等明细表查询结果。

待确认：
- HTML 展示行数上限是否固定为 1000。
- 下载格式是否后续统一为 Excel。
